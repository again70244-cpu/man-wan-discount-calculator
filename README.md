# 滿萬折抵計算

可加入手機桌面的網頁小工具（PWA），計算「滿萬送 1000」或「滿萬送 500」的領券與現抵金額。
純 HTML / JS，無需安裝任何套件，可離線使用。

## 計算邏輯（每張金額 = 1000 或 500）

- **方案A 領券**：`floor(總價 ÷ 10000) × 每張金額`
- **方案B 現抵**：
  1. 初步張數 = `floor(總價 ÷ 10000)`
  2. 實際張數 = `floor((總價 − 初步張數 × 每張金額) ÷ 10000)`
  3. 現抵金額 = 實際張數 × 每張金額

| 總價 | 滿萬送500 領券 | 滿萬送500 現抵 |
|---|---|---|
| 263,400 | 13,000 | 12,500 |
| 58,600 | 2,500 | 2,500 |
| 40,900 | 2,000 | 1,500 |

## 上線（GitHub Pages）

1. 到此 repo 的 **Settings → Pages**，Source 選 **GitHub Actions**。
2. 推送程式碼後，Actions 會自動部署，網址為 `https://<帳號>.github.io/man-wan-discount-calculator/`。

## 加到手機桌面

- **iPhone（Safari）**：開啟網址 → 分享按鈕 → 「加入主畫面」
- **Android（Chrome）**：開啟網址 → 右上角選單 → 「加到主畫面」/「安裝應用程式」
